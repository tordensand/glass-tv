# Glass TV

En Apple TV-inspirert startskjerm med glass-effekt for Samsung Tizen-TV-er (2017 og nyere), laget som en TizenBrew-modul.

## Installering
I TizenBrew på TV-en: Module Manager → legg til GitHub-modul → skriv `tordensand/glass-tv`.

## Fjernkontroll
- ◀ ▶ bla mellom apper
- OK åpne appen
- ▲ innstillinger (bytt bakgrunn: Auto, vinter, vår, sommer, høst, jul, nyttår, påske, 17. mai, halloween)
- Tilbake lukker innstillingene
